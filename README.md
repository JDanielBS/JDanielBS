### 👋 Sobre mí

Busco un puesto como **analista o científico de datos**. Me interesa llevar un problema de los datos crudos a un modelo o un análisis que se pueda defender: limpieza, comparación de modelos, métricas honestas y documentación. También he construido sistemas con LLMs (agentes, RAG) y APIs.
